# 飞马星球医院预约挂号系统 (Pegasus Planet Hospital)

## 项目简介
这是一个基于 Java Web (Servlet + JSP) 开发的医院预约挂号系统。系统包含前台患者预约端和后台管理端，支持医生排班、患者预约、报表统计、Excel导入导出等功能。

## 技术栈
- **后端**: Java Servlet, JSP, JDBC, Apache Commons FileUpload, Apache POI (Excel), iText (PDF), Gson
- **前端**: HTML5, CSS3, JavaScript, JSTL
- **数据库**: MySQL 8.0
- **服务器**: Tomcat 9.0

## 功能模块

### 1. 患者端
- **用户注册/登录**: 支持手机号注册，MD5密码加密。
- **科室/医生浏览**: 查看特色科室和医生团队详情。
- **在线预约**: 选择科室、医生、日期和时段进行挂号。
- **个人中心**: 查看预约记录（支持取消预约）、修改个人信息和密码。
- **公告查看**: 查看医院最新公告。

### 2. 管理端
- **仪表盘**: 查看今日预约、医生总数、患者总数等关键指标。
- **医生管理**: 增删改查医生信息，支持Excel批量导入。
- **排班管理**: 设置医生出诊时间，支持批量生成排班和Excel导入。
- **预约管理**: 查看所有预约记录，标记完成或取消预约，支持Excel导出。
- **患者管理**: 查看注册患者列表。
- **统计报表**: 
  - 月度预约统计
  - 科室挂号量统计
  - 医生工作量统计
  - 支持生成PDF报表

## 部署说明

1. **数据库初始化**:
   - 创建数据库 `hospital_db`
   - 运行 `sql/init_database.sql` 脚本建表和插入初始数据。

2. **配置数据库连接**:
   - 修改 `src/main/resources/db.properties` 中的数据库连接信息（URL, 用户名, 密码）。

3. **部署运行**:
   - 使用 Maven 构建项目: `mvn clean package`
   - 将生成的 WAR 包部署到 Tomcat 服务器。
   - 访问地址: `http://localhost:8080/project/`
